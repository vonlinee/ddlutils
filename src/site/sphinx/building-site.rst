Building the site
=================

The project site is generated by Maven and Sphinx. The Maven ``site`` lifecycle
copies the Sphinx sources to ``target/generated-site/sphinx``, generates the Ant
task reference from the ``@ant.*`` tags in the Java sources, and then runs Sphinx
to write the HTML site to ``target/site``.

Generate the site from the project root::

    mvn site

The generated Ant task reference is written to::

    target/generated-site/sphinx/generated/ant-task-reference.rst

Do not edit that generated file directly. Update the Java source comments under
``src/main/java/org/apache/ddlutils/task`` or the generator script under
``src/site/scripts`` instead.

Local preview
-------------

After ``mvn site`` completes, serve the generated HTML locally with Python::

    python -m http.server 8000 -d target/site

Open ``http://localhost:8000/`` in a browser to preview the site.

On Windows installations where the Python launcher is preferred, use::

    py -m http.server 8000 -d target/site

The same preview server can also be started through Maven::

    mvn -Pserve-site validate

The Maven preview profile serves ``target/site`` on port ``8000`` by default.
Override it with ``-Dsite.preview.port=9000`` when needed.
